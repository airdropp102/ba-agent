# BABOK v3 mapping for BA Studio

This is an **original implementation mapping** to BABOK Guide v3 task titles, **not official IIBA methodology, certification, or a reproduction of proprietary BABOK content**. Task names are verified from IIBA's public knowledge pages.

| BABOK knowledge area / task | BA Studio skills | Automated artifact / decision |
|---|---|---|
| 4.1 Prepare for Elicitation | ba-eliciting-requirements | source scope, intended stakeholders |
| 4.2 Conduct Elicitation | ba-eliciting-requirements, ba-clarifying-requirements | raw statements, questionnaire |
| 4.3 Confirm Elicitation Results | ba-clarifying-requirements | sourced answers, open questions |
| 4.4 Communicate BA Information | ba-clarifying-requirements | questionnaire / review draft |
| 4.5 Manage Stakeholder Collaboration | ba-orchestrating-analysis | owners, updates, iterative decisions |
| 7.1 Specify and Model Requirements and Designs | ba-normalizing-requirements | atomic FR/NFR, BR, goal mapping |
| 7.2 Verify Requirements and Designs | ba-detecting-gaps, ba-verifying-requirements | quality findings, traceability |
| 7.3 Validate Requirements and Designs | ba-verifying-requirements | stakeholder validation (manual) |
| 7.4 Define Requirements Architecture | ba-normalizing-requirements | canonical ID structure / trace matrix |
| 7.5 Define Design Options | ba-generating-deliverables | provisional prototype options |
| 7.6 Analyze Potential Value and Recommend Solution | ba-orchestrating-analysis | business goal alignment; human decision |

Out-of-scope for MVP: formal requirements change control, sign-off workflow, fully automated semantic contradiction analysis, source-level document page anchoring, and native editable Figma export.
